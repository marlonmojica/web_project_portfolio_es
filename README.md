# Portafolio Personal — Marlon Mojica

Sitio personal con mis proyectos destacados, habilidades técnicas y formas de contacto. Sprint 4 del bootcamp Full-Stack Web Development de TripleTen.

## 🔗 Demo en vivo

https://marlonmojica.github.io/web_project_portfolio_es/

## ✨ Funcionalidades

- **Diseño responsivo** completo con 3 breakpoints: desktop (1440px), tablet (768px) y móvil (320px).
- **3 desafíos con IA** implementados en CSS puro:
  - Subrayado con gradiente en los enlaces del perfil (verde HATO → verde neón).
  - Velo de oscurecimiento progresivo en las tarjetas de proyectos (linear-gradient + position absolute).
  - Fondo brillante con manchas de luz usando radial-gradient + calc para mantenerse relativo al centro de la pantalla.
- **Estructura semántica HTML5** + metodología **BEM** en CSS.
- **Fuentes locales** vía @font-face: Archivo Black (títulos) + Open Sans (texto).
- **Optimización de imágenes** para web (JPEG comprimido, SVG vectorial para íconos).

## 🛠️ Tecnologías

- **HTML5** semántico
- **CSS3**: Flexbox, Grid, Media Queries, Custom Properties, Linear y Radial Gradients, Aspect-ratio
- **Diseño base**: Figma
- **Hosting**: GitHub Pages
